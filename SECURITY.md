# Security

Never attach passwords, private SSH keys, API tokens, device backup images, personal rootfs archives or complete Wi-Fi profiles to issues. Redact logs before sharing them. SSH host-key verification must not be disabled to work around connection errors.

Root SSH access and a local maintenance interface are intentionally powerful. Keep the printer on a trusted network. Default device credentials should be replaced where possible. The installer can set a new root password and install a public key.
